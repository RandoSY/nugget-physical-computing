# New Lesson 11: where to begin

Start at `lessons/11-tiny-multitasker/README.md`. Run Stage 1, then Stage 2, then Stage 3; Stage 4 requires a G2ET to measure EnergyTrace. Each stage contains its own `main.c`, `edu430.h`, and `.projectspec`; Stage 3/4 contain `tiny_scheduler.h` and `button_filter.h`. The teacher notes and the addendum to `Teachers_Guide.pdf` document the investigations and grading.
