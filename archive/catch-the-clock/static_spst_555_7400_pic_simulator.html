Static Active Schematic

Live Nodes

Physical Meaning

SPST open: pull-up holds node at logic 1.

SPST closed: switch pulls node to ground, logic 0.

SET_N: active-low set input of 7400 latch.

Q: latched event bit read by PIC RA1.

555 OUT: a separate timing input read by PIC RA0.

PIC Black Box

IDLE

The PIC watches the pins, counts transitions, updates LEDs, and emits GSA text. It does not simulate sensors.

Display Design Correction

      
This version removes the continuous animation loop that made the display distracting. The schematic and dashboard update only after explicit state changes.

      
The optional 1 Hz heartbeat changes only the 555 output and is deliberately slow. It can be left in manual mode for a completely static display.

      
No HX711 or unrelated sensor state is included.
