# New Nugget, Core 12, and CRCL — historical concept white paper

Recovered from the user's Library during the September 2026 Intellectual Estate rescue.

This is a **historical architecture document**. It uses the earlier name **Core 12**. The current canonical curriculum root is **CORE 10**. The historical wording is intentionally preserved rather than silently rewritten.

The paper's central distinction remains useful:

- Core 12 / current CORE 10: use instruments and models to understand the measurable world.
- New Nugget: understand the machinery that creates computational capability.
- CRCL: a small instrument-command language that expresses laboratory intent.
- Bargain Bin Laboratory: inexpensive physical apparatus.
- Observatory Series: makes computation visible.

The original extracted text has been recovered from the surviving white-paper PDF and is preserved in ordered parts in this directory. It was checked for the protected IAS / Independence Assurance System material before public preservation; none was found.

Treat this as provenance and architectural history, not as a statement that the old Core 12 name supersedes CORE 10.
